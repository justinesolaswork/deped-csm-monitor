Step by step

Open the chat in this project (where you type to me).
Type /impeccable followed by what you want, for example:
/impeccable audit checks the dashboard for problems (readability, colors, phone layout) and lists them.
/impeccable critique gives design feedback, like a reviewer would.
/impeccable polish tidies small things: spacing, alignment, rough edges.
/impeccable clarify makes confusing text and labels clearer.
/impeccable distill removes clutter and simplifies.
/impeccable adapt fixes how it looks on phones and small screens.
Add a target if you want one, like /impeccable polish the Schools breakdown. Without a target, it looks at the whole thing.
Read what Claude finds or changes. Some commands only report; others edit your files. Tell me "only report, don't change anything" if you want to look first.
Run it, then check. I'll run npm run check. You open the dashboard (double-click start_dashboard.bat) and look.
Good to know

It follows PRODUCT.md (who the dashboard is for) and DESIGN.md (colors, fonts). You don't need to touch them.
You can also just describe what you want in normal words. I'll use it when it fits.
If you dislike a change, tell me and I'll adjust it.
A good first try is /impeccable audit. It's a safe starting point.
